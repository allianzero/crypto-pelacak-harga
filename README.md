# Crypto Pelacak Harga

Pelacak harga crypto live dalam Rupiah.

Koin: BTC, ETH, BNB, SOL, XRP, DOGE, ADA, TRX. Harga dari CoinGecko, refresh otomatis tiap 30 detik.

## Cara pakai

Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch → main) lalu buka link Pages-nya.

## Catatan

- Butuh internet — harga diambil live dari CoinGecko.
- Kalau CoinGecko tidak bisa dijangkau, halaman menampilkan pesan offline.
